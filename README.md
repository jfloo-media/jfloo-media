# jfloo-media

Public CDN for images used across jfloo.com editorial content (Sofia Bell articles).

Served via [jsDelivr](https://www.jsdelivr.com/): `https://cdn.jsdelivr.net/gh/jfloo-media/jfloo-media@main/<path>`

## Structure

- `sofia/<slug>/` — images for Sofia Bell articles, one folder per article slug.

All images are original, generated for jfloo.com editorial use.
